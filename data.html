Data and permissions

This guide describes the direct Mac preview.

Files and recovery

Choose the folders you want to browse. Prism uses macOS folder access and stores its settings on your Mac. On a normal quit, it saves a workspace checkpoint that can include unsaved editor text so you can resume next time.

Terminal and browser

Commands run as your macOS user. Prism can save submitted commands locally when terminal history is enabled. Background command notifications show the exit status and time by default. In Terminal settings, you can also show the command and folder in Notification Center. Your shell and the programs you run have their own settings and histories. The built-in browser contacts the sites you open and keeps browsing data by profile.

Optional assistants

When you use an assistant, the selected service or locally installed command receives the request and any context included with it. Check the selected provider and the files or text you share. The provider’s account and data terms apply to its service.

Updates and support

Update checks contact this site to retrieve the release feed. Downloading an update retrieves the selected archive. Prism verifies the publisher signatures. This site serves its fonts, screenshots and tour from the same host.

For support, share your Prism version, macOS version and steps to reproduce. Issue reports are public. Remove private paths, tokens and document contents before sharing an example. Open the support tracker
